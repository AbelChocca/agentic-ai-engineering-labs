# Agentic AI Engineering Labs

Repositorio de proyectos y laboratorios prácticos desarrollados durante mi formación en **Agentic AI Engineering**, con el objetivo de prepararme para la certificación **LangChain Certified Agent Engineer**.

Los proyectos exploran el desarrollo de agentes de IA, orquestación multiagente, integración de herramientas, Model Context Protocol (MCP) y aplicaciones basadas en LLMs utilizando el ecosistema de LangChain y LangGraph.
